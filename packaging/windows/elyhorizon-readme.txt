Elyhorizon for Windows x64

Use the Elyhorizon setup EXE to install the launcher and matching game together.
For the portable ZIP, extract the entire archive and keep horizon-launcher.exe
and horizon-client.exe in the same folder. Start horizon-launcher.exe and select your Ely.by account.
The bundled Horizon client is used for builds with matching Minecraft data pins.
Imported and native-mod builds retain their own client executable.

This archive contains Horizon's own programs, not Mojang game files or personal
account credentials. Official releases include their public Desktop application ID for browser sign-in
with S256 PKCE. No end-user environment setup or client secret is required.
See elyby-account.md for maintainer configuration and verification.
